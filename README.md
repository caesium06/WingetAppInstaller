# Winget App Catalog

A sleek, dark-mode Windows desktop app to **browse, search, install, update and uninstall** apps using the Windows Package Manager (`winget`) — styled like Microsoft Store.

Built with **Electron.js**.

---

## Features

- 🔍 **Search** — Live winget search with 40 results
- 🏠 **Home** — Category chips + featured apps
- 📦 **Library** — See all winget-managed installed apps
- ⬇️ **Install** — One-click install with streaming output
- 🎯 **Specific Version** — Choose any available version from a dropdown
- ⬆️ **Update** — Check for updates & update individual apps
- 🗑️ **Uninstall** — Two-click confirmed uninstall with live output
- 📋 **Copy Command** — Copies the winget command to clipboard
- ⌨️ **Shortcuts** — `Ctrl+F` to search, `Esc` to close modal

## Requirements

- Windows 10/11
- [Windows Package Manager (winget)](https://github.com/microsoft/winget-cli) — pre-installed on Windows 11

## Running from Source

```bash
git clone https://github.com/YOUR_USERNAME/Winget-App_catalog.git
cd Winget-App_catalog
npm install
npm start
```
